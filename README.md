# TOTAL IA

Primera versió de la PWA Total IA.

## Publicació
Puja `index.html`, `manifest.webmanifest` i `sw.js` a l'arrel del repositori.
Després activa GitHub Pages des de Settings > Pages, publicant des de la branca principal i carpeta `/ (root)`.

Aquesta versió és la interfície instal·lable. El motor d'IA s'afegirà en una fase posterior.
